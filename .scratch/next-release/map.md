# QuickTerm 下一版本决策地图

Label: wayfinder:map

## Destination

确定 QuickTerm 下一版本的核心用户、主要使用场景、功能范围与关键交互规则，最终形成可交给开发者的明确规格（`spec.md`）。本阶段只做决策和规格文档，不编写产品代码。

## Notes

- 当前为初始决策地图；目标与范围仍需与用户逐项确认，所有决策任务尚未解决。
- 每次只问一个简短问题，给出推荐和取舍理由，等待用户回答后再推进。
- 使用 `wayfinder`、`grilling` 和 `domain-modeling`；用户逐题讨论的要求优先于技能默认的批量提问。
- 上一轮分析、历史设计文档及本次推荐均是候选建议；代码是现状证据，不是下一版的需求承诺。
- 先读 [代码现状记录](baseline.md)，讨论时按需回到源码。持久化约定见 [任务跟踪规则](../../docs/agents/issue-tracker.md)。
- 任务在本事项目录的 `issues/` 中，依赖表达决策顺序，可随用户回答调整。仅在用户确认结论后记录 Answer 并标为 resolved。
- 核心用户和主场景未明确前，不确定键位方案、项目模型、浏览器定位或恢复等级。
