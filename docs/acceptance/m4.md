Two hard ones cleared during this session (details in porting-notes):

1. **macOS 26 CVDisplayLink per-session quota**: after several hundred surface creations Create fails
   (disguised as OOM), which killed builds all the way back through the historical tags. Tracked down
   with a Debug engine + @errorReturnTrace, and fixed at the root by injecting `window-vsync = false`
   into the overlay. If you want vsync, log out and back in, then override it in the config's `[ghostty]`.
2. **Test-host lifecycle strangling itself**: under TEST_HOST, state restore / closing a window on an
   empty tree / quitting on the last window all interfered with the tests, and `override func setUp() async`
   strips @MainActor, so publishing state from a background thread blew up the host.
   Fixed by isolating a test mode and removing the async setUp.
