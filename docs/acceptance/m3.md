Implementation notes:
- Theme assets: 22 official Omarchy themes (a snapshot of master, three more than the 19 that existed when this was designed: last-horizon, lupine, solitude); colors.toml goes into git, and one official background per theme is fetched by `scripts/fetch-themes.sh` (not in git)
- Live-switch path: ThemeManager rewrites the overlay → `ghostty.reloadConfig` at app level plus surface by surface across every workspace → the UI palette (status bar / borders / panels) follows; a light theme also drives the window appearance and `ghostty_app_set_color_scheme`
- Theme / background pickers: a Walker-style centred panel (Monaco, 2px accent border, square corners, 0.95 opacity), keyboard navigation with ↑↓ / Return / Esc plus clicking
