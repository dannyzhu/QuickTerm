## QuickTerm 1.6.8

通用二进制（Apple Silicon + Intel，macOS 15.4+），Developer ID 签名并经 Apple 公证。

### QuickTerm 会自己保持最新了
这是第一个内置更新器的版本。从现在起，QuickTerm 会在启动时以及大约每天一次检查 GitHub Releases，有新版本时状态栏最右侧会出现一个图标：

- 点击图标（或在 QuickTerm 菜单里选「检查更新…」）查看更新内容，按「安装并重启」；下载在后台进行，随后 app 自动重启进入新版本，布局保持不变；
- 设置 `install = true` 后，更新会静默下载并在你退出时安装；此时图标只提示重启即可完成，「立即重启」则马上完成安装；
- `[updates]` 段新增两个键：`check`（默认 true）和 `install`（默认 false，开启即隐含 check）。引擎自带的 `auto-update` 键会被忽略；
- 每个更新都用 QuickTerm 的 EdDSA 密钥签名，解包前先验签；本说明会按界面语言直接显示在 app 里。

1.6.7 及更早的版本没有更新器：这一版请手动安装一次，之后的版本会自动到来。

### 修复
- **剪贴板询问会得到回答，不再挂起。** 程序请求读取剪贴板（OSC 52，`clipboard-read = ask`，即默认值）、程序写入剪贴板（`clipboard-write = ask`）、或把带换行的内容粘贴进不支持括号粘贴的程序时，app 里没有任何东西回答引擎的询问：粘贴凭空消失、写入被丢弃、等待读取剪贴板的程序则永远等下去。现在每种情况都会在 pane 所在窗口弹出确认，显示涉及的文本，程序一定会收到答复。

### 从源码构建的用户
- Sparkle 2.10.0 通过 Swift Package Manager 引入，`xcodegen generate` 会自动拉取。
- `scripts/make-release.sh` 现在会用 Sparkle 密钥给 DMG 签名、生成 appcast，并把 DMG、校验和、两份说明与 appcast 作为一个 release 一起发布；见 README 中 *Build* 下的 *Releasing*，包括一次性的 `generate_keys` 步骤和 `--first-release`。
