## QuickTerm 1.5.3

Universal binary (Apple Silicon + Intel, macOS 15+), ad-hoc signed — see the README's *Install* section for the one-time Gatekeeper step.

### Highlights
- **`⌘`-click links open in a browser pane**: `⌘`-clicking an http(s) URL in a terminal opens it as a new tab in the workspace's most recently focused browser pane, or in a new browser pane beside the terminal if there is none. Other schemes (mailto, ssh, file paths) still go to the system; `link-opener = "system"` restores the default browser for everything.
- **Clear screen on `Cmd+Shift+K`** (`clear-terminal`): clears the screen and scrollback of the focused terminal (ghostty's `clear_screen`), since `Cmd+K` is the cheat sheet. Terminal panes only — with a browser pane focused the key passes through. Rebindable in `[keybinds]`; also in the Shell menu.

### Fixes
- `⌘`-click never reached the terminal at all before this release (the `⌘`-drag overlay swallowed the click), so link clicks did not even open the system browser. A click without a drag is now delivered to the pane; `⌘`-drag still moves and drops panes once the pointer travels a few points.
- `⌘` hovering a link shows the link pointer instead of the drag hand; the floating-pane `⌘`-drag no longer loses the first few points of motion and follows the pane rather than an array index if the layout changes mid-drag.
- `Cmd+Shift+K` with the Scratchpad open clears the Scratchpad, not a hidden tiled terminal; inside full-screen TUIs (vim, less) the key passes through to the program as ghostty intends.
- Shell / Pane menu shortcuts now obey `[keybinds]`: an unbound or rebound combo no longer fires from the menu.

### Config keys added
`link-opener`.
