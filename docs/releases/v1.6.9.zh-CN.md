## QuickTerm 1.6.9

通用二进制（Apple Silicon + Intel，macOS 15.4+），Developer ID 签名并经 Apple 公证。从 1.6.8 起 QuickTerm 会自动更新，这一版会通过状态栏图标送达。

### 修复
- **Claude Code 退出后，pane 不再一直显示「Claude Code · 已跑完」。** 两个问题叠在一起。agent 的 `Stop` 和 `SessionEnd` 钩子是异步运行的，到达 QuickTerm 的顺序不定；当 `Stop` 晚于 `SessionEnd` 到达时，它把已经释放的状态重新建了回来，而之后再没有任何东西能把它清掉。另外，进程扫描（agent 进程消失时兜底释放状态的机制）从来没认出过 Claude Code 的原生安装：`~/.local/bin/claude` 是指向 `~/.local/share/claude/versions/<版本>` 的符号链接，macOS 按目标文件给进程命名，所以规则文件里的 `process = ["claude"]` 从未匹配上。现在一个已结束的会话会保持结束状态几秒钟（该会话迟到的 `Stop` 或「task complete」文本会被丢弃，审批提示则永远放行），规则文件新增 `process-path`（可执行文件路径片段），原生安装因此能被识别。

### 诊断
- 按住 `⌘` 悬停在 pane 上本应出现抓手光标并可以拖动 pane；在某一台机器上没有任何反应，原因尚未查明。QuickTerm 现在会把这个状态的每次变化及其来源记入 `modifiers` 日志分类，用 `log stream --level debug --predicate 'subsystem == "dev.danny.quickterm" AND category == "modifiers"'` 就能看到链条断在哪里。

### 从源码构建的用户
- agent 规则文件（`Resources/agents/*.toml`）在 `process` 之外接受 `process-path = [...]`：与解析后的可执行文件路径做片段匹配。扫描仍然只在规则点名某个进程时才读取它的环境。
