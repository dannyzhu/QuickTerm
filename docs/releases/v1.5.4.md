## QuickTerm 1.5.4

Universal binary (Apple Silicon + Intel), ad-hoc signed — see the README's *Install* section for the one-time Gatekeeper step. **Requires macOS 15.4 or later** (was 15.0): the browser-extension support below is built on WebKit's `WKWebExtension` API, which first shipped in 15.4.

### Highlights
- **Browser extensions**: browser panes now run Chrome / Firefox-format WebExtensions through WebKit (the same engine and extension API Safari uses).
  - *Install from the Chrome Web Store*: open an extension's store page in a browser pane and click the **Add to QuickTerm** button that QuickTerm places next to the store's (greyed-out) "Add to Chrome"; QuickTerm downloads the CRX, lists the permissions it asks for, and installs on confirmation.
  - *Import from Chrome*: the puzzle-piece menu at the right end of the toolbar (`Cmd+Shift+E`) has "Import installed extensions from Chrome…", which copies the newest version of every extension in your local Chrome profile (themes and packaged apps are skipped).
  - *Manage*: enable / disable, open an extension's options page, remove. Each extension can be **pinned to the toolbar** exactly like Chrome — store installs are pinned by default, imports inherit your Chrome pin state, everything else lives in the puzzle menu (where "Open" still triggers it). Pinned extensions show an action button with badge and popup; page context menus gain the extensions' own items.
  - Extensions share cookies and sign-in state with your tabs. Files live in `~/Library/Application Support/QuickTerm/Extensions/`; `browser-extensions = false` turns the whole feature off.
  - *Scope*: WebKit implements about 25 WebExtension API namespaces. Not available: blocking `webRequest` (use `declarativeNetRequest`), `identity`, `history`, `downloads`, `management`, `proxy`, `debugger`, native messaging; `storage.sync` is local only.
- **Download progress**: a progress ring appears to the right of the address bar while downloading (aggregate across downloads; a spinning arc when the size is unknown; a check when everything finished, an exclamation mark when only failed/cancelled remain). Click it for the list: file name, received / total · %, a progress bar, cancel while in flight, Reveal in Finder when done, remove, and Clear finished. `browser-download-dir` (default `~/Downloads`) picks the folder. The list belongs to its pane; closing the pane cancels in-flight downloads.
- The address bar keeps at least 200 pt however many extensions are pinned; pinned buttons that do not fit are hidden and reachable from the puzzle menu.

### Config keys added
`browser-extensions` (default true), `browser-download-dir` (default `~/Downloads`).

### Keybinding added
`Cmd+Shift+E` — `web-extensions` (browser pane only): open the extensions menu.

## QuickTerm 1.5.4（中文）

通用二进制（Apple Silicon + Intel），ad-hoc 签名，首次打开请按 README「安装」一节处理 Gatekeeper。**需要 macOS 15.4 或更高**（原为 15.0）：下面的浏览器扩展建立在 WebKit 的 `WKWebExtension` API 上，该 API 从 15.4 起才有。

### 亮点
- **浏览器扩展**：浏览器 pane 通过 WebKit 运行 Chrome / Firefox 格式的 WebExtensions（与 Safari 同一引擎、同一套扩展 API）。
  - *从 Chrome Web Store 安装*：在浏览器 pane 里打开扩展的商店页，点 QuickTerm 放在商店（灰掉的）「添加至 Chrome」旁边的 **添加到 QuickTerm**；QuickTerm 下载 CRX、列出它要的权限，确认后安装。
  - *从 Chrome 导入*：工具条右端的拼图菜单（`Cmd+Shift+E`）里「从 Chrome 导入已安装扩展…」，把本机 Chrome 配置里每个扩展的最高版本复制过来（主题、打包应用跳过）。
  - *管理*：启用 / 停用、打开选项页、移除。每个扩展可像 Chrome 一样**固定到工具条**——商店安装默认固定，导入沿用你在 Chrome 里的固定状态，其余都在拼图菜单里（「打开」照样能触发）。固定的扩展有带 badge 的动作按钮与 popup；页面右键菜单带扩展自己的菜单项。
  - 扩展与标签共享 cookie 与登录态。文件在 `~/Library/Application Support/QuickTerm/Extensions/`；`browser-extensions = false` 整体关闭。
  - *支持范围*：WebKit 实现约 25 个 WebExtension API 命名空间。不支持：阻断式 `webRequest`（用 `declarativeNetRequest`）、`identity`、`history`、`downloads`、`management`、`proxy`、`debugger`、原生消息；`storage.sync` 只存本地。
- **下载进度**：下载时地址栏右侧出现进度环（多下载汇总；总量未知转动的弧；全部完成打勾、只剩失败 / 取消显示感叹号）。点击展开列表：文件名、已收 ÷ 总量 · 百分比、进度条、进行中可取消、完成后「在 Finder 中显示」、移除、清除已完成。`browser-download-dir`（默认 `~/Downloads`）指定目录。列表随 pane，关 pane 取消在途下载。
- 不管固定了多少扩展，地址栏至少保留 200 pt；放不下的固定扩展隐藏，从拼图菜单可开。

### 新增配置项
`browser-extensions`（默认 true）、`browser-download-dir`（默认 `~/Downloads`）。

### 新增快捷键
`Cmd+Shift+E` —— `web-extensions`（仅浏览器 pane）：打开扩展菜单。
