## QuickTerm 1.5.9

Universal binary (Apple Silicon + Intel, macOS 15.4+), ad-hoc signed — see the README's *Install* section for the one-time Gatekeeper step.

The headline is a **control plane**: a Unix-domain socket plus a `quickterm` command that can query and drive screens, workspaces and panes — everything the keybindings do, plus composing a whole workspace in one call — and an MCP server so an AI agent (Claude Code, Codex) gets typed tools instead of scraping help text.

### Control plane
- `quickterm state | list | get` — the session as JSON: screens, workspaces, panes, and now **geometry for every pane** (normalised rect, point size, terminal cols/rows, dwindle split ratio or scrolling column width).
- `quickterm action <name>` — all 67 keybinding actions, verbatim.
- `quickterm pane|workspace|screen|app …` — 19 curated commands. Every one is an **absolute setter, never a toggle** (`--zoom on`, `set-layout dwindle`, `--width 0.33`), so an agent that retries a command cannot silently undo itself. `--dry-run` and `--fail-if-noop` everywhere.
- `quickterm spec dump|validate|apply` — a public `quickterm.workspace/1` schema: dump a workspace, edit two fields, apply it back; or compose a three-column layout with commands running in it from a single JSON document. `dump → apply → dump` is a fixed point.
- `quickterm pane resize` — `--ratio`, `--points`, `--split <path>`, `--dir left|right|up|down`: the same outcomes a mouse drag or the resize keybindings produce, sharing the same clamping code rather than re-implementing it.
- `quickterm events poll|follow` — a monotonic `seq` plus typed events (pane opened/closed, focus, layout, workspace, title, cwd). Events never carry pane output.
- `quickterm describe --json` — the whole surface as machine schema in one call: commands, argument types, safety classes, exit codes, event types, the spec schema and all 67 actions. This is what you hand an agent.
- `quickterm mcp` — an MCP stdio server whose 11 tools are generated from the same command table, with readOnly/destructive/idempotent annotations so a host can auto-approve reads and prompt on the rest.
- Every pane gets `QUICKTERM_SOCKET` / `QUICKTERM_PANE` / … in its environment, so an agent running *inside* a pane can drive the terminal around it with zero configuration.

**Security posture**: on by default in `ask` mode. Same-uid peer check on the socket (0600 in a 0700 directory); reads are free but browser URLs and titles are redacted for callers without the per-launch token; mutations are silent yet visible (a status-bar flash naming the originating pane) and undoable; destructive and sensitive commands prompt once per calling process, naming the real process and pane. `send-text` is off by default, and even when on, writing into a pane other than the caller's own prompts every time — the caller's identity is an HMAC, not a self-reported value.

### Also in this release
- **A launch hang is fixed** — and it would have hit this very release. macOS binds privacy (TCC) grants to a binary's code signature, so a newly installed build has no grant; an ungranted app started from the Dock that opens `~/Documents`, `~/Desktop` or `~/Downloads` blocks **forever, with no prompt**, and session restore opens each pane's saved directory. QuickTerm now probes those three roots off the main thread with a short deadline and falls back to the default directory instead of hanging. See *Known limit* below.
- **Terminal context menu trimmed** to Copy / Paste / Reset Terminal / Terminal Read-only / Change Terminal Title, plus a new **Search with Google "…"** that searches your selection in the most recently used browser pane instead of the system browser. The system Services submenu is gone (its own "Search With Google" opened Safari).
- **Config keys are now grouped by function** — `[appearance]`, `[workspace]`, `[terminal]`, `[browser]`, `[control]` — generated from one registry, which also drives the template, validation and both READMEs. Every previous key spelling keeps working unchanged; you do not need to touch your config.
- **New switches, both on by default**: `[control] socket` (the listener) and `[control] mcp` (the MCP server), so you can keep the CLI for yourself while refusing MCP hosts.

### Known limit (macOS, not QuickTerm)
Because the app is ad-hoc signed, each new build is a new identity to macOS, so the privacy grant does not carry over. After installing this version, panes whose saved working directory is under `~/Documents`, `~/Desktop` or `~/Downloads` will start in your home directory until you grant the app access under System Settings → Privacy & Security → Files and Folders. This is a fallback, not data loss: the real paths stay in the session archive.

## QuickTerm 1.5.9（中文）

通用二进制（Apple Silicon + Intel，macOS 15.4+），ad-hoc 签名，首次打开请按 README「安装」一节处理 Gatekeeper。

这一版的主角是**控制面**：一条 Unix socket 加一个 `quickterm` 命令，可以查询和操作屏幕、工作区、pane —— 快捷键能做的它都能做，还能一条命令组合出整个工作区；另外带一个 MCP server，让 AI agent（Claude Code、Codex）拿到的是带类型的工具，而不是去啃帮助文本。

### 控制面
- `quickterm state | list | get` —— 会话的 JSON：屏幕、工作区、pane，并且**每个 pane 都带几何信息**（归一化矩形、点尺寸、终端行列数、dwindle 的分割比例或 scrolling 的列宽）。
- `quickterm action <名字>` —— 全部 67 个快捷键动作，原样直通。
- `quickterm pane|workspace|screen|app …` —— 19 条精选命令，一律是**绝对设值而非 toggle**（`--zoom on`、`set-layout dwindle`、`--width 0.33`）：agent 看不到当前状态，一条 toggle 重试一次就会把自己撤销。`--dry-run` 与 `--fail-if-noop` 全线支持。
- `quickterm spec dump|validate|apply` —— 公开的 `quickterm.workspace/1` 格式：导出一个工作区、改两个字段、装回去；或者用一份 JSON 直接拼出三列布局并在里面跑命令。`dump → apply → dump` 是不动点。
- `quickterm pane resize` —— `--ratio`、`--points`、`--split <路径>`、`--dir left|right|up|down`：与鼠标拖拽、调整大小快捷键**完全等价**，而且共用同一套钳制代码，不是照抄规则。
- `quickterm events poll|follow` —— 单调的 `seq` 加类型化事件（pane 开关、焦点、布局、工作区、标题、目录）。事件**永远不携带 pane 的输出内容**。
- `quickterm describe --json` —— 一次吐出整个控制面的机器可读描述：命令、参数类型、安全分级、退出码、事件类型、spec schema、67 个动作。给 agent 的就是这一份。
- `quickterm mcp` —— MCP stdio 服务，11 个工具由同一张命令表生成，带只读 / 破坏性 / 幂等注解，宿主可以自动放行只读、对其余弹确认。
- 每个 pane 的环境里都有 `QUICKTERM_SOCKET` / `QUICKTERM_PANE` 等变量：**跑在 pane 里的 agent 零配置就能操控它周围的终端**。

**安全默认**：默认开启、`ask` 模式。socket 同 uid 校验（0700 目录下的 0600）；读操作免确认，但无 token 的调用方读不到浏览器网址与标题；变更静默执行但**可见**（状态栏闪一下并注明来源 pane）且可撤销；破坏性与敏感操作按调用进程确认一次，对话框显示真实进程名与来源 pane。`send-text` 默认关闭，即使打开，写**非调用方自己**的 pane 每次都要确认——调用方身份是 HMAC 验证的，不是自报的。

### 本版其它内容
- **修掉一个启动卡死** —— 而且它本来正要打到这个版本上。macOS 的隐私授权（TCC）绑定在二进制的代码签名上，新装的构建等于新身份、没有授权；未授权的应用从 Dock 启动后去打开 `~/Documents`、`~/Desktop`、`~/Downloads` 会**永久阻塞且不弹授权框**，而恢复会话恰好要打开每个 pane 存下来的目录。现在这三个受保护目录改为在主线程之外探测、超时即退回默认目录，不再卡死。见下方「已知限制」。
- **终端右键菜单精简**为 Copy / Paste / Reset Terminal / Terminal Read-only / Change Terminal Title，并新增 **Search with Google "…"**：把选中的文字丢进**最近用过的浏览器 pane** 搜索，而不是跳去系统浏览器。系统的 Services 子菜单已移除（它里面那条 "Search With Google" 会打开 Safari）。
- **配置项按功能分组** —— `[appearance]`、`[workspace]`、`[terminal]`、`[browser]`、`[control]`，由一张登记表生成，模板、校验与中英两份 README 也出自同一张表。**所有旧写法继续有效**，你的配置文件一个字都不用改。
- **两个新开关，默认都开**：`[control] socket`（监听）与 `[control] mcp`（MCP 服务）——可以自己留着命令行用，同时拒绝任何 MCP 宿主接入。

### 已知限制（来自 macOS，不是 QuickTerm）
由于应用是 ad-hoc 签名，每个新构建对 macOS 来说都是新身份，隐私授权不会延续。装上本版之后，保存的工作目录在 `~/Documents`、`~/Desktop`、`~/Downloads` 下的 pane 会从家目录启动，直到你在「系统设置 → 隐私与安全性 → 文件与文件夹」里给它授权。这只是退回默认目录，**不是数据丢失**：真实路径仍保存在会话存档里。
