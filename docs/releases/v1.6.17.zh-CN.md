## QuickTerm 1.6.17

通用二进制（Apple Silicon + Intel，macOS 15.4+），Developer ID 签名并经 Apple 公证。通过更新器送达。

### 修复
- **工作区切回来时保持离开时的样子。** 滚动布局下，切到别的工作区再切回来，以前会回到最前面的几列、激活第一个 pane，然后再滑动。现在每个工作区记住自己激活的 pane 和滚动位置：离开时显示第 2、3 列并激活 3，回来还是 2、3、激活 3，画面完全不动。
- **中文固定用苹方显示。** Monaco 没有中文字形，引擎要借别的字体来显示。汉字它交给 macOS 去选，得到的是苹方；但 `，`、`（` 这类全角标点，它在已安装的字体里搜，先搜到哪个字体（霞鹜文楷、宋体等），之后的中文就都用那个字体。现在内置的引擎配置把中文的编码范围直接映射到苹方（PingFang SC）。
- 这次只改了**你没有自己的 Ghostty 配置文件时** QuickTerm 用的内置配置。如果你有自己的配置（`~/.config/ghostty/config`），加上这一行，效果相同：

  ```
  font-codepoint-map = U+3000-U+303F,U+3400-U+4DBF,U+4E00-U+9FFF,U+F900-U+FAFF,U+FF00-U+FFEF=PingFang SC
  ```

  请用这一行，不要再加一行 `font-family = PingFang SC`：Monaco 没有粗体字形，多一个字体时，引擎会把粗体英文（提示符、`ls` 列出的目录名）也用苹方显示。
