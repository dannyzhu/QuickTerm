## QuickTerm 1.6.17

通用二进制（Apple Silicon + Intel，macOS 15.4+），Developer ID 签名并经 Apple 公证。通过更新器送达。

### 修复
- **中文固定用苹方显示。** Monaco 没有中文字形，引擎要借别的字体来显示。汉字它交给 macOS 去选，得到的是苹方；但 `，`、`（` 这类全角标点，它在已安装的字体里搜，先搜到哪个字体（霞鹜文楷、宋体等），之后的中文就都用那个字体。一个会话最后用哪个字体，取决于先出现的是汉字还是标点。现在内置的引擎配置把苹方（PingFang SC）列为第二字体，所有中文都会落在苹方上。
- 这次只改了**你没有自己的 Ghostty 配置文件时** QuickTerm 用的内置配置。如果你有自己的配置（`~/.config/ghostty/config`），在 `font-family` 那一行下面加一行 `font-family = PingFang SC`，效果相同。
