## QuickTerm 1.6.19

通用二进制（Apple Silicon + Intel，macOS 15.4+），Developer ID 签名并经 Apple 公证。通过更新器送达。

### 新功能
- **开箱识别 Antigravity CLI（`agy`）。** 内置 agent 规则新增 `antigravity`（现共五个：`antigravity`、`claude-code`、`codex`、`gemini`、`kiro-cli`），默认启用。它原生发出的 OSC 7501 状态报告（`app=antigravity`）会直接驱动 pane 顶部状态条、`quickterm agents list` 与通知提醒——即使可执行文件被命名为 `gemini` 等其他名字，收到实时的 OSC 7501 报告后也会自动接管进程扫描产生的 `unknown` 占位状态。

### 修复
- **后台守护进程残留的 `QUICKTERM_PANE` 不再把状态落到错误的 pane 上。** `quickterm agent-event` 现在要求调用 hook 的进程必须位于目标 pane 自身的进程树内，不在进程树内的事件会以 `origin_mismatch` 拒绝丢弃。这修复了 Codex 默认共享后台服务把所有会话的 hook 都报给第一个启动 `codex` 的 pane 的问题；给 Codex 加上 `--no-daemon`（如 `alias codex='codex --no-daemon'`）即可让钩子回到当前 pane 内执行。
