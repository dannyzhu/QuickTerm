## QuickTerm 1.5

**Universal binary** — this release runs natively on both Apple Silicon and Intel Macs (macOS 15+). The DMG is ad-hoc signed; see the README's *Install* section for the one-time Gatekeeper step.

### Highlights
- **Universal DMG** (arm64 + x86_64); `GHOSTTYKIT_TARGET=universal` builds the engine for both architectures.
- **Quit semantics**: `Cmd+Q` asks for confirmation while panes are open and quits immediately when none are; closing the last pane keeps the window open with a hint.
- **Layout toggle memory**: `Cmd+L` restores the previous arrangement of the other layout when the pane set is unchanged (no more flattened columns).
- **Scrolling peek**: 1.5% of each neighbouring column peeks in symmetrically around the focused column.
- **Engine fallback config**: when you have no Ghostty config at all, a bundled default (Monaco 15, Builtin Pastel Dark, copy-on-select, 100M scrollback…) applies; it steps aside as soon as you create one.
- **Config file completeness**: `config.toml` is created on first launch and missing keys are appended as commented defaults; new `divider-opacity` (dwindle divider line, default 0.2).
- **Focus fixes**: no more multiple “active” panes after `Cmd+L`; hover always re-focuses; unfocused panes no longer blink their cursor after state restore.
- **Backgrounds**: all Omarchy wallpapers per theme plus your own images (`~/.config/quickterm/backgrounds/`), grid keyboard navigation.

### Notes
- Ghostty engine: libghostty 1.3.1. QuickTerm loads your Ghostty config itself (XDG and Application Support, old and new file names) and no longer triggers libghostty's empty-template write.

## QuickTerm 1.5（中文）

**通用二进制**——Apple Silicon 与 Intel Mac 均可原生运行（macOS 15+）。DMG 为 ad-hoc 签名，首次打开请按 README「安装」一节处理 Gatekeeper。

### 亮点
- **通用 DMG**（arm64 + x86_64）；`GHOSTTYKIT_TARGET=universal` 为两种架构构建引擎。
- **退出语义**：有 pane 时 `Cmd+Q` 先确认，没有时直接退出；关掉最后一个 pane 窗口保留并提示新建。
- **布局往返记忆**：`Cmd+L` 在 pane 集合不变时恢复另一布局的原排布。
- **scrolling 露边**：焦点列两侧对称露出邻列 1.5%。
- **引擎兜底配置**：没有任何 Ghostty 配置时应用内置缺省（Monaco 15、Builtin Pastel Dark、copy-on-select 等），有了自己的配置即让位。
- **配置文件完整性**：首次启动生成 `config.toml`，缺失键以注释补全；新增 `divider-opacity`（dwindle 分隔细线，默认 0.2）。
- **焦点修复**：`Cmd+L` 后不再多 pane 同时激活；悬停总能重新聚焦；状态恢复后非激活 pane 光标不再闪烁。
- **背景**：每主题全部 Omarchy 壁纸 + 自选图片（`~/.config/quickterm/backgrounds/`），网格键盘导航。
