## QuickTerm 1.5.2

Universal binary (Apple Silicon + Intel, macOS 15+), ad-hoc signed — see the README's *Install* section for the one-time Gatekeeper step.

### Highlights
- **Embedded browser panes** (`Cmd+B`): a pane can now be a WKWebView with a slim toolbar (back / forward / reload, address bar, progress). Sessions persist across panes and restarts, the UA masquerades as Safari by default (Google sign-in rejects embedded browsers), downloads land in `~/Downloads`, and JS dialogs work. Browser-only keys — back `Cmd+Shift+[`, forward `Cmd+Shift+]`, reload `Cmd+R`, address bar `Cmd+Shift+L`, zoom `Cmd+=` / `-` / `0`, open in the system browser `Cmd+Shift+O` — are consumed only while a browser pane has focus, everything else still reaches the terminal.
- **Browser tabs**: one WKWebView per tab — `Cmd+N` new tab, `Ctrl+Tab` / `Ctrl+Shift+Tab` to cycle, `Cmd+W` closes the tab and only closes the pane on the last one, `Cmd`+click opens a background tab. `window.open` / `target=_blank` create a real tab (so `opener` and `postMessage` work and popup sign-in flows complete), `window.close` closes it. Tabs are saved with the workspace.
- **Tab strip design**: trapezoid tabs with a real hierarchy — the active tab is painted in the page colour and joins the toolbar, inactive tabs sit a layer back and lift on hover, revealing a close button on the right. Tabs share the strip between `browser-tab-min-width` and `browser-tab-width` and scroll sideways once they hit the minimum (the active tab is always revealed). The strip is visible by default (`browser-tab-bar = "auto"` restores hide-on-single-tab) and ends in a `+` button that opens a new tab.
- **File-manager pane** (`Cmd+Shift+B`): opens a pane running `yazi` (configurable via `file-manager-command`; `lf` and `ranger` work too) in the focused pane's directory. Quitting the file manager reopens a terminal in place — in the directory you browsed to.
- **Floating panes resize by dragging** (`Cmd`+drag): the middle moves the pane, the four edges resize along one axis, the corners along both, with the opposite edge staying put. Holding `Cmd` shows the matching cursor.

### Fixes
- Scrolling: a newly split or dragged-out column inherited the two-column default width instead of the current column's width factor, so column widths stopped being equal.
- Browser address bar: pressing Return navigated to the page you were on instead of what you typed.
- Browser panes did not take focus on hover while inactive.
- `Cmd+Shift+[` / `Cmd+Shift+]` were dead keys (Shift leaked into the symbol key); the Edit menu swallowed the terminal's `Cmd+X` / `Cmd+Z` / `Cmd+A`.

### Config keys added
`browser-home`, `browser-search`, `browser-user-agent`, `browser-inspectable`, `browser-tab-bar`, `browser-tab-width`, `browser-tab-min-width`, `file-manager-command`.

Browser pane limits: no Widevine DRM (Netflix / Spotify web), no system password autofill or passkeys — use `Cmd+Shift+O` to finish such flows in the system browser.

## QuickTerm 1.5.2（中文）

通用二进制（Apple Silicon + Intel，macOS 15+），ad-hoc 签名，首次打开请按 README「安装」一节处理 Gatekeeper。

### 亮点
- **内嵌浏览器 pane**（`Cmd+B`）：pane 可以是 WKWebView + 薄工具条（后退/前进/刷新、地址栏、进度）。登录态跨 pane、跨重启保留，默认伪装 Safari UA（Google 登录页拒绝嵌入式浏览器），下载落到 `~/Downloads`，JS 对话框可用。浏览器专属键——后退 `Cmd+Shift+[`、前进 `Cmd+Shift+]`、重载 `Cmd+R`、地址栏 `Cmd+Shift+L`、缩放 `Cmd+=` / `-` / `0`、系统浏览器打开 `Cmd+Shift+O`——只在焦点是浏览器 pane 时消费，其余照常给终端。
- **浏览器多标签**：每标签一个 WKWebView——`Cmd+N` 新标签、`Ctrl+Tab` / `Ctrl+Shift+Tab` 切换、`Cmd+W` 关标签（最后一个才关 pane）、`Cmd`+点击链接后台开。`window.open` / `target=_blank` 开的是真标签（`opener`、`postMessage` 可用，弹窗登录能走完），`window.close` 关标签。标签随工作区存档。
- **标签条设计**：梯形标签、层次分明——当前标签填页面底色、与工具条连成一体；非激活标签退后一层，悬停浮起并在右侧露出关闭钮。标签在 `browser-tab-min-width` 与 `browser-tab-width` 之间等分标签条，到最小仍放不下就横向滚动（当前标签始终滚入视野）。标签条默认常显（`browser-tab-bar = "auto"` 可恢复单标签隐藏），右端 `+` 点击新建标签。
- **文件管理器 pane**（`Cmd+Shift+B`）：在焦点 pane 的目录里开一个跑 `yazi` 的 pane（`file-manager-command` 可配，`lf`、`ranger` 亦可）。退出文件管理器后原位开终端——落在你浏览到的目录。
- **浮动 pane 拖动缩放**（`Cmd`+拖动）：中间移动，四边沿单轴缩放，四角双轴缩放，对边不动；按住 `Cmd` 悬停即显示对应光标。

### 修复
- scrolling：新拆出/拖出的列用的是两列默认宽度而不是当前列的宽度因子，列宽不再等分。
- 浏览器地址栏回车导航到的是原页面而不是输入的网址。
- 浏览器 pane 非激活时鼠标移上去不聚焦。
- `Cmd+Shift+[` / `Cmd+Shift+]` 是死键（Shift 混进符号键）；Edit 菜单吞掉终端的 `Cmd+X` / `Cmd+Z` / `Cmd+A`。

### 新增配置项
`browser-home`、`browser-search`、`browser-user-agent`、`browser-inspectable`、`browser-tab-bar`、`browser-tab-width`、`browser-tab-min-width`、`file-manager-command`。

浏览器 pane 边界：无 Widevine DRM（Netflix / Spotify 网页版）、无系统密码填充与通行密钥——这类流程用 `Cmd+Shift+O` 转到系统浏览器完成。
