## QuickTerm 1.6.17

Universal binary (Apple Silicon + Intel, macOS 15.4+), signed with a Developer ID and notarized by Apple. Arrives through the updater.

### Fixes
- **Chinese text stays in PingFang.** Monaco has no Chinese glyphs, so the engine has to borrow them. It asked macOS for ideographs, which answers PingFang, but searched the installed fonts for full-width punctuation such as `，` and `（`, and whichever font that turned up first (LXGW WenKai, Songti, …) was then used for every Chinese character after it. Which font a session ended up in depended on whether a character or a punctuation mark appeared first. The bundled engine config now names PingFang SC as the second font, so every Chinese character lands on it.
- This changes only the config QuickTerm uses when you have **no Ghostty config file of your own**. If you have one (`~/.config/ghostty/config`), add `font-family = PingFang SC` under your `font-family` line to get the same result.
