## QuickTerm 1.6.17

Universal binary (Apple Silicon + Intel, macOS 15.4+), signed with a Developer ID and notarized by Apple. Arrives through the updater.

### Fixes
- **A workspace comes back the way you left it.** In the scrolling layout, switching to another workspace and back used to reset it to the first columns with the first pane focused, then slide. Each workspace now keeps its focused pane and its scroll position: left showing columns 2 and 3 with 3 focused, it comes back showing 2 and 3 with 3 focused, with no movement on screen.
- **Chinese text stays in PingFang.** Monaco has no Chinese glyphs, so the engine has to borrow them. It asked macOS for ideographs, which answers PingFang, but searched the installed fonts for full-width punctuation such as `，` and `（`, and whichever font that turned up first (LXGW WenKai, Songti, …) was then used for every Chinese character after it. The bundled engine config now maps the Chinese ranges straight to PingFang SC.
- This changes only the config QuickTerm uses when you have **no Ghostty config file of your own**. If you have one (`~/.config/ghostty/config`), add this line to get the same result:

  ```
  font-codepoint-map = U+3000-U+303F,U+3400-U+4DBF,U+4E00-U+9FFF,U+F900-U+FAFF,U+FF00-U+FFEF=PingFang SC
  ```

  Use this line, not a second `font-family = PingFang SC`: Monaco has no bold face, and with a second family the engine draws bold Latin text (prompts, directory names in `ls`) in PingFang too.
