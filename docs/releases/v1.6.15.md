## QuickTerm 1.6.15

Universal binary (Apple Silicon + Intel, macOS 15.4+), signed with a Developer ID and notarized by Apple. Arrives through the updater.

### Fixes
- **The grab hand comes and goes with `⌘`, on every pane.** 1.6.14 gave the pane's drag overlay a SwiftUI pointer style, which fixed the hand appearing but left it behind: once `⌘` was released the hand stayed over every pane except the last one, because a style on a view that is added and removed is not reliably cleared on removal. The style now lives on the pane itself and is switched off when `⌘` is released; measured in a scratch window with the pointer pinned, it gave the hand while held and the terminal's I-beam after release in every round, where the previous placement flickered between hand, arrow and I-beam.
