## QuickTerm 1.6.12

Universal binary (Apple Silicon + Intel, macOS 15.4+), signed with a Developer ID and notarized by Apple. Arrives through the updater.

### Fixes
- **The grab hand now appears over every tiled pane when `⌘` is pressed, not only over some.** 1.6.11 set the hand the moment the drag overlay joined the window, but the overlay gets its size a moment later, so the check could run against an empty frame and miss the very pane the pointer was over: in a two-pane split on a Mac mini the hand showed over one pane and not the other, while both dragged fine. The check now also runs once the overlay has its frame.
