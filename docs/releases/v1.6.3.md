## QuickTerm 1.6.3

Universal binary (Apple Silicon + Intel, macOS 15.4+), ad-hoc signed — see the README's *Install* section for the one-time Gatekeeper step.

The first real session with agent awareness surfaced a notification gap; this release closes it.

### Notifications come back when you look away
An agent would block on an approval or a choice, the pane's red mark and the workspace pill would both show it — and yet no macOS banner and no Dock badge arrived. The interrupting signals (banner + Dock badge) only ever fired at the moment the prompt was raised, and only if the pane was inactive then:

- A prompt raised **while you were looking at the pane** got no banner (correct), but none ever appeared after you switched away.
- Once you pressed a key in the pane, the alarm was quieted; leaving the pane never un-quieted it, so the badge and banner stayed dark even after you walked away with the prompt still pending — while the pane mark and pill kept showing it.

Now, when a pane that still needs you goes from focused to unfocused, the interrupting signals come back: the Dock badge counts it again and the banner is presented then — the one path by which a prompt raised while you were watching the pane finally reaches you. It still stays quiet while you are actually in the pane, and the Dock badge still counts panes you have left (unchanged from 1.6.2).

The banner plays a sound only the first time a pane is announced, tracked per pane — so a pane described by two agents' prompts, or a glance-and-leave, does not ping twice.

### Also
- Fixed a pre-existing case where focusing a pane whose "task complete" note resolved in the same pass left the approval banner stuck on screen; the banner is now withdrawn when you open the pane.
- The build and release scripts are now all in English, matching the rest of the project.

### Reminder
macOS only delivers banners to an app it launched as a real app (through Finder or `open`) and only when notifications are allowed for QuickTerm in System Settings ▸ Notifications. The Dock badge does not depend on either and always reflects the panes waiting for you.
