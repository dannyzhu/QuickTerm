## QuickTerm 1.6.5

Universal binary (Apple Silicon + Intel, macOS 15.4+), ad-hoc signed — see the README's *Install* section for the one-time Gatekeeper step.

This release adds two tools for diagnosing notifications, and carries the 1.6.4 fix that makes the Dock badge a persistent "an agent needs you" light.

### A notification self-test
Run this inside any pane:

```
quickterm notices test
```

It raises a synthetic "needs you" alarm on that pane — exactly as an agent would — so you can watch the Dock badge, the pane mark and (when that pane is not the one you are looking at) a banner appear, then it clears itself after 15 seconds. With `--json` it also reports what *should* have happened, which is the useful part when something doesn't:

- `badgeExpected` — the number the Dock badge should show;
- `systemNotifications` — whether macOS will deliver banners at all (`authorized` / `denied` / `notDetermined` / `unavailable`);
- `bannerExpected` and `banner` — whether a banner should appear and, if not, why (this pane is active, banners are off, or macOS has them denied).

That tells apart the two very different causes of "nothing showed up": the alarm never fired, or it fired and macOS is not delivering it.

### A diagnostic log
Turn on `[notifications] diagnostic-log = true` and QuickTerm writes every step of the notification and agent-state path to `~/Library/Logs/QuickTerm/diagnostics.log`: each agent event and the state it produced, every notice posted / quieted / re-armed / resolved, the counts each surface then reads, when the Dock badge is set, and every banner presented, skipped (with the reason) or refused by macOS. Titles only — a title is payload-free by construction, and a notice body is never written. Off by default.

### Carried from 1.6.4
The Dock badge counts every pane that needs you — the same as the pane's red mark and the workspace number — and stays until the prompt is answered, acknowledged, or the agent moves on, regardless of whether you are looking at the pane or have typed into it. The banner stays polite: only when the pane isn't the one you're looking at.
