## QuickTerm 1.6.18

Universal binary (Apple Silicon + Intel, macOS 15.4+), signed with a Developer ID and notarized by Apple. Arrives through the updater.

### New
- **Panes come back with their output.** On quit, each terminal pane saves its last 5000 lines, colours included. The next launch shows them again above a dim `─── Restored … ───` line. Saved content is encrypted with AES-GCM by default, with the key in your login keychain, and is deleted as soon as it has been read. Full-screen programs save nothing. Settings are under `[restore]`: `content`, `lines`, `encrypt`, `agent-resume`.
- **Resume the agent you left.** If Codex, Claude Code or kiro-cli was running in a pane when you quit, the pane's top band offers a button that runs the agent's resume command for that session. Kiro-cli 3.0 is recognised, and `quickterm hooks install kiro-cli` installs its hook.
- **Program status (OSC 7501).** Any program can tell the terminal what it is doing with an escape sequence (working, done, waiting for you, error, with progress and a message). QuickTerm shows it in the pane's top band and raises the same alarms an agent does. Codex already sends it, so Codex is tracked even without a hook. Try `sh -c 'printf "\e]7501;state=working:app=cargo:progress=40\e\\"; sleep 10'`. A printed report can never clear an alarm a hook raised, and a program flipping in and out of "waiting" makes at most one sound a second. `quickterm state` lists the records per pane as `programs`. `[agents] program-status = false` turns it off.
- **A saved Ghostty config takes effect at once.** Editing `~/.config/ghostty/config` now reloads it immediately, open panes included, with no restart or Cmd+Shift+,. `[terminal] watch-ghostty-config = false` turns this off.
