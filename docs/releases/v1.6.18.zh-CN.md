## QuickTerm 1.6.18

通用二进制（Apple Silicon + Intel，macOS 15.4+），Developer ID 签名并经 Apple 公证。通过更新器送达。

### 新功能
- **重新打开后，pane 里的输出还在。** 退出时，每个终端 pane 保存最后 5000 行输出，颜色一起保存。下次启动时重新显示出来，下面有一条淡色的 `─── Restored … ───` 分隔线。保存的内容默认用 AES-GCM 加密，密钥放在登录钥匙串里，读过一次就删除。全屏程序不保存。设置在 `[restore]` 下：`content`、`lines`、`encrypt`、`agent-resume`。
- **恢复退出前的 agent 会话。** 退出时如果某个 pane 里正在运行 Codex、Claude Code 或 kiro-cli，这个 pane 顶部的状态条会出现一个按钮，点一下就为那个会话执行 agent 的恢复命令。现在能识别 kiro-cli 3.0，`quickterm hooks install kiro-cli` 会安装它的 hook。
- **程序状态（OSC 7501）。** 任何程序都可以用一条转义序列告诉终端自己在做什么（运行中、完成、等你处理、出错，可以带进度和说明）。QuickTerm 把它显示在 pane 顶部的状态条里，提醒方式和 agent 一样。Codex 已经会发这种报告，所以没装 hook 也能跟踪 Codex。可以试试 `sh -c 'printf "\e]7501;state=working:app=cargo:progress=40\e\\"; sleep 10'`。程序打印出来的报告永远清不掉 hook 发出的提醒；程序反复进出“等你处理”时，每秒最多响一次。`quickterm state` 按 pane 列出这些记录，字段是 `programs`。`[agents] program-status = false` 可以关掉。
- **Ghostty 配置保存后立即生效。** 修改 `~/.config/ghostty/config` 后马上重新加载，已经打开的 pane 也会更新，不用重启，也不用按 Cmd+Shift+,。`[terminal] watch-ghostty-config = false` 可以关掉。
