## QuickTerm 1.5.5

Universal binary (Apple Silicon + Intel), ad-hoc signed — see the README's *Install* section for the one-time Gatekeeper step. Requires macOS 15.4 or later.

### Highlights
- **Browser-extension compatibility shim.** Several popular Chrome extensions were dead on WebKit for reasons that had nothing to do with their features; QuickTerm now rewrites each extension on install (and once, on the next launch, for extensions installed earlier) so its background runs behind a small compat layer:
  - **Tampermonkey** — WebKit drains the microtask queue after every `importScripts()` call, which flipped Tampermonkey's startup flag before its listeners were registered (popup spun forever); its Chrome build also hard-codes `chrome-extension:` as its own page scheme, so it rejected its own popup on `webkit-extension://`. Both are handled: empty scripts are skipped by `importScripts`, and the literal scheme is rewritten in the extension's scripts.
  - **Stylish** — its background threw at startup on the missing `webNavigation.onHistoryStateUpdated`; now a no-op event. Clicking its toolbar icon used to crash the page ("page process crashed repeatedly"): the side panel is an extension iframe embedded in the web page, and WebKit kills the page process when such a frame calls `tabs`, `windows`, `action`, `scripting`, `alarms`, `contextMenus` or `cookies` directly. Those calls are now relayed through the extension's background instead.
  - The original manifest entry is kept under `__quickterm`; extension updates regenerate the shim. Known limits: relayed calls in callback form do not see `runtime.lastError`, function arguments (e.g. `scripting.executeScript` with `func`) cannot cross the relay, and extensions whose core feature WebKit lacks (proxy switchers such as ZeroOmega need `chrome.proxy`) still cannot work.
- **Two-finger horizontal swipe over the focused browser pane** now goes to the page (horizontal scroll / back-forward gesture) instead of panning the scrolling canvas. Unfocused browser panes and terminals behave as before.

### Build
- `project.yml` disables `ENABLE_USER_SCRIPT_SANDBOXING`, which xcodegen 2.46 turns on by default and which broke the Ghostty resource-bundling script.
