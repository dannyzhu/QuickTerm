## QuickTerm 1.6.7

Universal binary (Apple Silicon + Intel, macOS 15.4+). **Signed with a Developer ID and notarized by Apple**: download, open, done — the one-time right-click-to-open step in the README's *Install* section is no longer needed.

### Cmd-clicking a link inside Claude Code (or any other TUI) opens it in the browser pane
With a program that has mouse reporting on, the engine used to hand a Cmd-click on a URL to the program instead of treating it as a link, and the program opened it itself in the system browser — QuickTerm's `link-opener = browser-pane` never got a say. Now a Cmd-click on a link is a link click wherever it happens, and the program does not see it. Shift+Cmd-click keeps working as before.

### The agent status strip has its own band
The strip that shows who is in a pane and what they are doing no longer lives inside the terminal's own padding, which forced `pane-padding` to stay at 12 or more just to leave it room. It now reserves a band of its own at the top of every terminal pane:

- the first row of the terminal hugs the strip, with no dead gap below it;
- the band is held whether or not there is anything to draw, so an agent starting or finishing never nudges the terminal — a blank band is painted in the terminal's own background and simply reads as more terminal;
- the line reads `title · agent · state`; a pane title you set no longer replaces the agent's name;
- two new `[agents]` keys: `strip-height` (default 16, 0 switches the band off) and `strip-font-size` (default 11);
- `pane-padding` now defaults to 8, since nothing depends on it any more.

The bottom of a pane keeps at most one partial row of empty space: that is the remainder of the height that does not divide into whole rows, and it is now as small as it can be.

### Fixes
- **Native fullscreen no longer jumps in height** when you swipe to another Space and back. The Dock reappearing on the other Space made the window refit itself to the smaller visible area, and macOS then snapped it back.
- **Notifications**: the app now asks for badge permission (so the Dock badge and the *Badge app icon* switch work), a notice for the pane you are looking at is delivered to Notification Center instead of being dropped, and the authorization state is re-read after you grant it. With `[notifications] diagnostic-log = true` the log records every delivery decision.
- **Long informational alerts** (agent hook status, control plane activity, hook install failures, the CLI installer's output) show their text in a scrollable, selectable area, so the alert no longer balloons to fit forty lines and paths can be copied out.

### For people building from source
- QuickTerm's own changes to the vendored engine now live as diffs under `patches/ghostty/`, applied by `scripts/build-ghosttykit.sh` before every build.
- On macOS 27 / Xcode 27 the engine has to be built against the Command Line Tools' `MacOSX26.5.sdk` (`GHOSTTYKIT_SDK=…`); see `docs/porting-notes.md` for why.
