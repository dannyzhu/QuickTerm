## QuickTerm 1.6.16

通用二进制（Apple Silicon + Intel，macOS 15.4+），Developer ID 签名并经 Apple 公证。通过更新器送达。

### 新增
- **`Cmd+F` 在 pane 内搜索。** 终端 pane 右上角弹出搜索框，所有匹配高亮；回车跳到下一个，Shift+回车跳到上一个，到头后循环。浏览器 pane 搜索当前网页。Esc 关闭搜索框并清除高亮。
- **放大的 pane 有标识。** 右上角显示一个半透明的缩小图标，点击退出放大。
- **交换 pane 有滑动动画。** `Cmd+Shift+←↑↓→` 交换时，两个 pane 滑到对方的位置，尺寸不同时同时缩放。`swap-animation-duration` 设置时长（默认 0.5 秒，0 关闭动画）。

### 变更
- **放大改为 `Cmd+Shift+F`**，`Cmd+F` 留给搜索，和其他应用一致。
- **滚动布局：露在屏幕边缘的列改为点击激活。** 鼠标划过它不再带动整条滑动；其他地方的悬停聚焦不变。
- **滚动布局：双指滑动一次一列。** 把那一侧藏着的列滑出来并激活它，不会停在两列之间。

### 诊断
- 诊断日志（`diagnostic-log = true`）现在记录每次 agent 状态变化所在的 pane、屏幕和工作区，以及每个 hook 背后的进程链。用来排查"一个 pane 的 agent 状态显示到另一个 pane 上"的问题；带 `MISMATCH` 的那一行就是要发给我们的。
