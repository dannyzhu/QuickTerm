## QuickTerm 1.6.8

Universal binary (Apple Silicon + Intel, macOS 15.4+), signed with a Developer ID and notarized by Apple.

### QuickTerm now keeps itself up to date
This is the first release with a built-in updater. From here on, QuickTerm checks GitHub Releases at launch and about once a day, and a newer version shows up as an icon at the right end of the status bar:

- click the icon (or choose **Check for Updates…** in the QuickTerm menu) to see what is new and press **Install and Relaunch**; the download runs in the background and the app restarts into the new version with your layout intact;
- with `install = true` the update is downloaded silently and installed when you quit; the icon then only says that a restart will finish it, and **Restart Now** does that on the spot;
- two new keys under `[updates]`: `check` (default true) and `install` (default false, implies `check`). The engine's own `auto-update` keys are ignored;
- every update is signed with QuickTerm's EdDSA key and verified before it is unpacked, and these notes are shown inside the app in the language of the interface.

Versions up to 1.6.7 have no updater: install this one by hand once, and the next ones arrive by themselves.

### Fixes
- **Clipboard questions are answered instead of left hanging.** When a program asked to read the clipboard (OSC 52 with `clipboard-read = ask`, the default), when a program wrote to it with `clipboard-write = ask`, or when a paste with a line break went into a program that does not bracket pastes, nothing in the app answered the engine's question: the paste vanished, the write was dropped, and a program waiting for a clipboard read waited forever. Each case now shows a sheet on the pane's window with the text in question, and the program always hears back.

### For people building from source
- Sparkle 2.10.0 is pulled in through Swift Package Manager; `xcodegen generate` fetches it.
- `scripts/make-release.sh` now signs the DMG with Sparkle's key, writes the appcast and publishes it with the DMG, its checksum and both notes files as one release; see *Releasing* under *Build* in the README, including the one-time `generate_keys` step and `--first-release`.
