## QuickTerm 1.6.4

Universal binary (Apple Silicon + Intel, macOS 15.4+), ad-hoc signed — see the README's *Install* section for the one-time Gatekeeper step.

### The Dock badge is now a real "an agent needs you" light
1.6.3 fixed the notification that never came back after you left a pane. Using it turned up the deeper problem: the Dock badge counted only panes you had **not touched yet**, and answering a prompt means pressing Tab or an arrow to move between the options — so the badge cleared on that first keystroke, before you had decided anything. If you sat in the agent pane and worked, you never saw it.

The badge now counts every pane that needs you, the same as the pane's red mark and the workspace number, and it stays until the prompt is actually answered, acknowledged, or the agent moves on — whether or not you are looking at the pane or have typed into it.

The system banner is unchanged and stays polite: it still only appears when the pane needing you is **not** the one you are looking at, so it never interrupts you mid-keystroke, and it comes back when you switch away with a prompt still pending (the 1.6.3 fix).

### Reminder
macOS delivers banners only to an app it launched as a real app (Finder or `open`) and only when notifications are allowed for QuickTerm in System Settings ▸ Notifications. The Dock badge does not depend on either.
