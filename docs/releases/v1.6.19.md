## QuickTerm 1.6.19

Universal binary (Apple Silicon + Intel, macOS 15.4+), signed with a Developer ID and notarized by Apple. Arrives through the updater.

### New
- **Antigravity CLI (`agy`) is recognised out of the box.** `antigravity` joins the bundled agent rules (`antigravity`, `claude-code`, `codex`, `gemini`, `kiro-cli`) and is enabled by default. Its native OSC 7501 status reports (`app=antigravity`) drive the pane's agent status bar, `quickterm agents list`, and notifications directly — even when the binary is installed under another name such as `gemini`, where the live OSC 7501 report now replaces the process scan's `unknown` placeholder.

### Fixes
- **Stale `QUICKTERM_PANE` events from background daemons no longer land on the wrong pane.** `quickterm agent-event` now requires the calling hook process to sit inside the target pane's own process tree, refusing events whose inherited `QUICKTERM_PANE` outlived or left that tree (`origin_mismatch`). This stops Codex's shared background app-server from attributing every session's hooks to whichever pane ran `codex` first; start Codex with `codex --no-daemon` (`alias codex='codex --no-daemon'`) so its hooks run inside the pane.
